# Documentação

Este diretório concentra a documentação do projeto em dois níveis:

- leitura para iniciantes, com explicação de conceitos do zero;
- leitura técnica de arquitetura para manutenção e evolução.

## Ordem recomendada de leitura

1. [Guia Completo para Iniciantes](./guia-iniciante.md)
2. [Trilha de Estudo em 3 Dias](./trilha-3-dias.md)
3. [Arquitetura Técnica](./architecture.md)

## Quando usar cada arquivo

- `guia-iniciante.md`: quando você ainda não domina PHP, Laravel, APIs REST, SQL, Docker, Git, HTTP/HTTPS, OpenAPI/Swagger e precisa entender o projeto com linguagem simples.
- `trilha-3-dias.md`: quando você quer um plano objetivo de estudo e prática para dominar o projeto em 3 dias.
- `architecture.md`: quando você já entende os conceitos e quer detalhes de organização de código, camadas e decisões técnicas.
